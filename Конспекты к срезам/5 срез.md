**Определение СУБД** — программное обеспечение для создания, хранения, изменения, удаления и получения данных в БД, а также управления доступом к ним.

**Функции СУБД:**

- хранение и управление данными;
- выполнение запросов;
- добавление / изменение / удаление данных;
- управление транзакциями;
- обеспечение целостности данных;
- управление доступом и правами;
- резервное копирование и восстановление;
- многопользовательский доступ и конкурентная работа.

**Типы СУБД:**

- **реляционные (SQL)** — данные в таблицах, связи между таблицами;
- **документные (NoSQL)** — данные в виде документов;
- **ключ-значение** — значение доступно по уникальному ключу;
- **колоночные** — данные организованы по колонкам, эффективны для аналитики;
- **графовые** — данные представлены вершинами и связями;
- **временные (Time-Series)** — оптимизированы для данных, привязанных ко времени.

**Кратко чем хорош каждый тип:**

- **Реляционные (SQL):** строгая структура, связи между таблицами, ACID-транзакции, сложные запросы. Хороши для банковских/бизнес-систем.
- **Документные (NoSQL):** гибкая структура документов, удобно хранить сложные/вложенные объекты, легко изменять схему.
- **Ключ-значение:** очень быстрый доступ по ключу. Хороши для кэшей, сессий, счётчиков, временных данных.
- **Колоночные:** высокая производительность на больших объёмах данных и при распределённом хранении; хорошо для аналитики и больших потоков данных.
- **Графовые:** эффективны для данных, где важны **связи между объектами** — социальные сети, рекомендации, зависимости.
- **Временные (Time-Series):** оптимизированы для данных с временной шкалой — метрики, логи, мониторинг, цены, показания датчиков.
